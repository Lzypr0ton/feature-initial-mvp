# Ecosystem notes

axe and Lighthouse provide developer-focused automated accessibility/performance testing. WAVE is an accessibility evaluation tool. Siteimprove and Silktide offer commercial enterprise monitoring. AccessSure and other India-focused services should be evaluated from publicly documented capabilities before comparison. This project’s opportunity is transparent, open-source evidence collection and an explicit versioned mapping to GIGW 3.0; it makes no exclusivity or superiority claim.
