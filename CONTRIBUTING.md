# Contributing

Use Node 22+, run lint, typecheck, tests and build before a PR. Use conventional commits (`feat:`, `fix:`, `docs:`, `test:`, `refactor:`, `chore:`). New GIGW rules require an authoritative source reference, stated automation limits, fixture coverage, and evidence/remediation output. Do not describe generic WCAG checks as GIGW-specific without an explicit GIGW reference.
